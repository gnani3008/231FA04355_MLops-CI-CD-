Pipeline

  1. Load and preprocess the data, then select the top features.
  2. Serve features through a Feast feature store (entity patient_id, view patient_features).
  3. Train six models and log one MLflow run each (parameters and metrics).
  4. Register the best model as Version 1, change one hyperparameter, retrain, register Version 2.
  5. GitHub Actions runs pytest and the training script on every push.
